
# School Management System

Залікова робота з програмування на Python.

## Опис проєкту

Програма для керування школою, класами, учнями та працівниками.

## Основні можливості

**Сценарій 1:**
- Завантаження учнів із CSV.
- Статистика школи.
- Побудова 4 графіків.
- Переведення класів на наступний рік.

**Сценарій 2:**
- Розрахунок зарплат працівників.
- Збереження результатів у CSV.

## Технології

Python, ООП, CSV, Matplotlib, Streamlit.

## Запуск

Встановлення бібліотек:

```bash
pip install matplotlib streamlit
```

Перший сценарій:

```bash
python -m streamlit run app.py
```

Другий сценарій:

```bash
python salaries.py
```

## Принципи ООП

Спадкування, поліморфізм, інкапсуляція та абстракція.
